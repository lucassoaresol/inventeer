## Durable clarification

Tickets Home is an organization-scoped read surface, not a browser-only view over one page of
Ticket data. An entitled requester sees the active organization's tickets, stable global counters,
server-side state filtering, pagination, a visible attention marker, and a row action that opens the
same Ticket Detail address used by direct links and notifications.

## Decisions preserved

- The list is organization-wide for an entitled viewer; access is not limited to tickets created by
  the current requester.
- Portal API remains canonical for status taxonomy, counter totals, filtering, search semantics,
  ordering, and pagination.
- Six presentation counters can group the seven canonical statuses without changing the persisted
  lifecycle model.
- Filtering must happen server-side. Filtering only the current offset page would make rows,
  counters, and pagination disagree.
- `Waiting on you` receives a semantic marker that tests can assert independently of color.
- The table displays the public Ticket reference and requester-visible fields; it does not expose
  internal Linear or Labs data.
- Selecting a row navigates to a stable detail URL rather than depending on an in-memory object.
